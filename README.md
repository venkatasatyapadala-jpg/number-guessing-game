# Number Guessing Game 🎮

A simple Python game where the computer randomly selects a number, and the player tries to guess it.

## Features

* Random number generation
* User-friendly hints (`Too High` / `Too Low`)
* Unlimited attempts until the correct guess
* Displays a congratulatory message when the number is guessed correctly

## How to Play

1. Run the program.
2. Guess a number between **1 and 100**.
3. The program will tell you whether your guess is:

   * **Too High**
   * **Too Low**
4. Keep guessing until you find the correct number.

## Requirements

* Python 3.x

## How to Run

```bash
python game.py
```

## Example

```text
Guess a number between 1 and 100: 50
Too Low!

Guess a number between 1 and 100: 75
Too High!

Guess a number between 1 and 100: 68
Congratulations! You guessed the correct number.
```
